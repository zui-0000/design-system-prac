# Flexbox で並べる

記録日: 2026-10-17

段階 1 で Card を作ったときに学んだ、`display: flex` の基本。「`inline-flex`」の節は、段階 3 で Button を作ったときに足した（2026-10-18）。

## 何が起きるのか

`display: flex` を付けた要素を **flex コンテナ**、その**直接の子**を **flex アイテム**と呼ぶ。flex アイテムが、決めた向きに並ぶ。

```html
<!-- .row が flex コンテナ、A・B・C が flex アイテム -->
<div class="row">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>
```

```css
.row {
  display: flex;
}
```

| 指定            | 見た目                                       |
| --------------- | -------------------------------------------- |
| なし            | `div` は 1 つで 1 行を使うので、縦に積まれる |
| `display: flex` | 横一列に並ぶ                                 |

`display: flex` は**親**に付ける。子に付けると、その子の中身が並ぶだけになる。

## 並べ方を決めるプロパティ

どれも親（コンテナ）に書く。

| プロパティ        | 決めること                     | よく使う値                                                                |
| ----------------- | ------------------------------ | ------------------------------------------------------------------------- |
| `flex-direction`  | 並べる向き                     | `row`（横、初期値）／`column`（縦）                                       |
| `gap`             | アイテムの間の余白             | `0.5rem` など                                                             |
| `justify-content` | 並ぶ方向での寄せ方             | `flex-start`／`center`／`space-between`（両端に寄せて、間を均等にあける） |
| `align-items`     | 並ぶ方向と直角の方向での揃え方 | `stretch`（初期値、伸ばす）／`center`                                     |
| `flex-wrap`       | 入りきらないときに折り返すか   | `nowrap`（初期値）／`wrap`                                                |

`justify-content` と `align-items` は、`flex-direction` によって向きが入れ替わる。

- 横並び（`row`）: `justify-content` が横の寄せ方、`align-items` が縦の揃え方
- 縦並び（`column`）: その逆

覚え方: **`justify` は並ぶ方向、`align` はその直角**。

## 余白は子の margin ではなく `gap` で決める

子に `margin` を付けて回ると、最初や最後の子だけ余白を消す、といった調整が必要になる。`gap` はアイテムの**間**にだけ余白を入れるので、1 か所で決まり、崩れにくい。

### 1 か所だけ間隔を変えたいとき

`gap` はすべての間に同じ余白を入れるので、1 か所だけ変えることはできない。基本の考え方は「**`gap` で揃えて、例外だけ margin**」。

**やり方 1: その要素にだけ margin を足す**

flex アイテムの margin は `gap` に**足し算**される。

```css
.card {
  display: flex;
  flex-direction: column;
  gap: 0.75rem; /* 基本の間隔 */
}

.footer {
  margin-top: 0.5rem; /* footer の上だけ 0.75 + 0.5 = 1.25rem になる */
}
```

Card の `.footer` の `padding-top: 0.5rem` も同じ考え方で、本文と操作の間だけを広くしている（関係のあるものは近く、別のまとまりとは広く）。

足し算になるのは flex アイテムだから。flex を使わない普通の縦積みでは、上下に並んだ margin は足されず、大きいほうだけが残る（**margin の相殺**）。flex アイテムでは相殺が起きない。

**やり方 2: まとまりごとに包む**

違う間隔が何種類もあるときは、要素をまとまりで包み、それぞれに `gap` を付ける。

```html
<!-- .card は gap: 1.5rem（まとまり同士は広く）、.header は gap: 0.25rem（見出しと補足は近く） -->
<article class="card">
  <div class="header">
    <h2>見出し</h2>
    <p>補足</p>
  </div>
  <div class="body">本文</div>
</article>
```

どの間隔も `gap` で決まるので、margin で個別に調整する場所がなくなる。「この要素同士は仲間」という構造が HTML に表れるのも利点。

| 状況                   | やり方                                     |
| ---------------------- | ------------------------------------------ |
| 1 か所だけ少し変えたい | `gap` + その要素に margin を足す           |
| 間隔が何種類もある     | まとまりごとに包んで、それぞれに `gap`     |
| 一番下（端）に寄せたい | `margin-top: auto`（余った空きを全部取る） |

## Card での使い方

`src/components/ui/Card/Card.module.css` より。

```css
.card {
  display: flex;
  flex-direction: column; /* 見出し・本文・操作を縦に並べる */
  gap: 0.75rem;
}

.footer {
  display: flex; /* ボタンの間を gap でそろえる（並ぶ向きは初期値の row で、横） */
  gap: 0.5rem;
  margin-top: auto; /* 余った高さを上に取って、一番下へ寄せる */
}
```

- 縦に並べる flex の中に、横に並べる flex を入れている。この**入れ子**が Flexbox の普通の使い方
- `margin-top: auto` は flex アイテムで使える技。`auto` の margin が余った空きを全部取るので、`.footer` はカードの一番下に押し出される。高さの違うカードを並べても、ボタンの位置がそろう

### flex は直接の子にしか効かない

```
.card（flex・縦）        ← title・body・footer を縦に並べる
├── .title  「見出し」
├── .body   「本文」
└── .footer（flex・横）  ← ボタンたちを横に並べる
    ├── <button>
    └── <button>
```

- `.card` の flex が並べるのは、直接の子の `title`・`body`・`footer` だけ。footer の中のボタンは `.card` から見ると**孫**なので、`.card` の flex は効かない
- ボタンの間を `gap` でそろえるには、ボタンの直接の親の `.footer` に `display: flex` を付ける

footer にだけ flex を付けたのは、**中に並べたいものが複数あるのが footer だけ**だから。

| 要素      | 中身                 | flex が必要か                          |
| --------- | -------------------- | -------------------------------------- |
| `.title`  | 文字だけ             | いらない。文字は普通に流れて表示される |
| `.body`   | 文字だけ             | いらない                               |
| `.footer` | ボタンが複数入る想定 | いる。ボタンの間を `gap` で揃えたい    |

ボタンは、flex がなくても横に並ぶ（外が inline のため。下の「`inline-flex`」の節）。footer を flex にするのは、間を `gap` でそろえるため。

### 1 つの要素が「アイテム」と「コンテナ」を兼ねる

`.footer` は 2 つの役を同時に持っている。

- **`.card` から見ると flex アイテム**: `margin-top: auto` で、カードの一番下に寄せられる
- **ボタンから見ると flex コンテナ**: `display: flex` と `gap` で、ボタンを横に並べられる

それぞれの箱は「自分の直接の中身をどう並べるか」だけに責任を持つ。外側の `.card` は footer の中身を知らなくてよい。React のコンポーネントを組み合わせるのと同じ考え方。

## `inline-flex`: 外への並び方と、中の並べ方

Button の CSS は `display: inline-flex` にしている（docs/13）。`flex` との違いは、要素の**外**にある。

### `display` は 2 つのことを決めている

上の「1 つの要素が『アイテム』と『コンテナ』を兼ねる」の 2 つの役を、`display` は 1 つの値でまとめて決めている。

- **外**（アイテムとしての役）: 親の中で、自分がどう並ぶか
- **中**（コンテナとしての役）: 自分の子を、どう並べるか

| 書き方        | 2 語で書くと  | 外                                  | 中   |
| ------------- | ------------- | ----------------------------------- | ---- |
| `flex`        | `block flex`  | 1 つで 1 行を使う（前後で改行する） | flex |
| `inline-flex` | `inline flex` | 文字のように、行の中に並ぶ          | flex |
| `grid`        | `block grid`  | 1 つで 1 行を使う（前後で改行する） | grid |
| `inline-grid` | `inline grid` | 文字のように、行の中に並ぶ          | grid |

TS の型で書くと、外と中の組み合わせになる。

```ts
type Outside = "block" | "inline"; // 外: 親の中で、自分がどう並ぶか
type Inside = "flex" | "grid"; // 中: 自分の子を、どう並べるか
type Display = `${Outside} ${Inside}`; // "inline flex" など
```

これはたとえ話ではなく、CSS の仕様がこの形になっている。`display: inline flex` と 2 語でも書ける（Chrome 115・Firefox 70・Safari 15 から）。このリポジトリでは、よく見る 1 語の書き方を使う。

Chromium で、幅 400px の親の中に、前後の文字と一緒に置いて測った。

| 要素と指定                  | 前後の文字と同じ行に並ぶか | 幅                                   |
| --------------------------- | -------------------------- | ------------------------------------ |
| `<div>` に `flex`           | 並ばない（前後で改行する） | 400px（親の幅いっぱい）              |
| `<div>` に `inline-flex`    | 並ぶ                       | 中身の幅                             |
| `<button>` に `flex`        | 並ばない（前後で改行する） | 中身の幅（`<div>` と違って伸びない） |
| `<button>` に `inline-flex` | 並ぶ                       | 中身の幅                             |

`<button>` の外は、ブラウザの初期値（`inline-block`）で inline になっている。

### インラインのものは、flex がなくても横に並ぶ

文字・`<a>`・`<button>`・`<svg>`（アイコン）は、もともと外が inline のもの。文章の中の単語のように、行の中を横に流れる。flex がなくても横に並ぶ。

最初の表で、flex がないと縦に積まれたのは、`<div>` が 1 つで 1 行を使う（外が block の）ものだから。`<li>`・`<p>`・`<h2>` も同じ。

インラインのものを flex で並べて良くなるのは、並ぶことではなく、**そろうこと**。

|              | flex なし                                                                                                                | flex あり                                            |
| ------------ | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| 縦のそろえ方 | 文字の下の線（ベースライン）にそろう。20px のアイコンと 16px の文字で測ると、アイコンの中心が文字の中心より 4px 上だった | `align-items: center` で真ん中にそろう（ずれは 0px） |
| 間のあけ方   | 子に margin を付けて回る                                                                                                 | `gap` で決める                                       |

### flex のアイテムになると、外の値は使われない

flex コンテナの直接の子は、外の値が block に変わる（`inline-flex` は `flex` に、`inline-block` は `block` に）。アイテムがどう並ぶかは、親の flex が決めるため。

Card の `.footer`（flex）の中の Button は、開発者ツールの Computed で見ると `display: flex` になっている。`.footer` の flex を外すと、`inline-flex` に戻る。Button の外を inline にした意味が出るのは、flex でない親の中（文章の中など）に置いたとき。

### どちらを使うか

| 置き方                                                   | 使う値        | このリポジトリの例                                          |
| -------------------------------------------------------- | ------------- | ----------------------------------------------------------- |
| 1 つで 1 行を使う箱にする（カード、ヘッダーの中身など）  | `flex`        | Card の `.card`・`.footer`、ヘッダーの `.inner`・`.navList` |
| 文字のように、行の中に置く小さな部品にする（ボタンなど） | `inline-flex` | Button の `.button`                                         |

## Grid との使い分け

|         | 得意なこと                                                              |
| ------- | ----------------------------------------------------------------------- |
| Flexbox | **1 方向**に並べる。ボタンの列、カードの中身の縦積みなど                |
| Grid    | **縦と横の 2 方向**を同時に揃える。カードの一覧、ページ全体の枠組みなど |

## 試し方

ブラウザの開発者ツールで `display: flex` のチェックを外すと、子が 1 行を使うものか、インラインのものかで結果が変わる。

**子が 1 行を使うもの（縦に積まれる）**: `vp dev` で練習ページ（/practice）を開き、ヘッダーの `.navList`（`_navList_` で始まるクラス）の `display: flex` のチェックを外す。リンクを包む `<li>` は 1 つで 1 行を使うので、縦に積まれる。

**子がインラインのもの（横に並んだまま）**: Storybook の UI/Button → WithPrimaryAndSecondary を開き、次の順に試す。

1. 2 つのボタンを包む `div` の `display: flex` のチェックを外す（Styles の `element.style` の欄）。ボタンは横に並んだまま、間の `gap`（8px）だけが消えてくっつく
2. ボタンの `.button`（`_button_` で始まるクラス）の `display: inline-flex` を `flex` に書き換える。外が block になり、ボタンが 1 つずつ改行されて縦に積まれる。幅は中身の幅のまま
3. 1 で外した `display: flex` を戻す。ボタンはまた横に並ぶ。flex のアイテムになると、外の値は使われないため
