# Grid で並べる

記録日: 2026-10-18

段階 1 でカードの一覧（`CardList`）を作ったときに学んだ、CSS Grid の基本。

## Flexbox との違い

|         | 得意なこと                                                              |
| ------- | ----------------------------------------------------------------------- |
| Flexbox | **1 方向**に並べる。ボタンの列、カードの中身の縦積みなど                |
| Grid    | **縦と横の 2 方向**を同時に揃える。カードの一覧、ページ全体の枠組みなど |

考え方は Flexbox と同じで、`display: grid` を付けた親が **grid コンテナ**、その直接の子が **grid アイテム**になる（[docs/04](04-Flexbox%20で並べる.md)）。違うのは、アイテムを 1 方向に並べるか、縦横のマス目に置くか。

## 1 行で、列の数が勝手に変わる

`src/components/features/Card/CardList/CardList.module.css` より。

```css
.list {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(16rem, 100%), 1fr));
  gap: 1.5rem;
}
```

| 部分                    | 意味                                                                           |
| ----------------------- | ------------------------------------------------------------------------------ |
| `grid-template-columns` | 列の作り方を決める                                                             |
| `repeat(auto-fit, …)`   | **列の数を決めずに**、入るだけ列を作る                                         |
| `minmax(下限, 1fr)`     | 1 列の幅は下限より狭くしない。余った幅は `1fr`（1 つ分の割合）ずつ均等に分ける |
| `min(16rem, 100%)`      | 下限は 16rem。ただし一覧の幅自体が 16rem より狭いときは、一覧の幅を下限にする  |

**列の数ではなく「1 列の最小の幅」を決める。** 画面の幅を見て列の数を切り替えるメディアクエリが要らない。

`min(16rem, 100%)` がないと、16rem より狭い画面で列が入りきらず、横にはみ出す。

### 実際に測った結果

| 画面の幅        | 列の数 | 同じ行のカードの高さ             | 横のはみ出し |
| --------------- | ------ | -------------------------------- | ------------ |
| 1280px          | 4 列   | 4 枚とも 231px でそろった        | なし         |
| 800px           | 2 列   | 行ごとにそろった（207px・159px） | なし         |
| 375px（スマホ） | 1 列   | 1 枚ずつ、中身に合った高さ       | なし         |

## ボタンの位置がそろう仕組み

Grid と Flexbox の役割分担の、典型的な例。

1. **Grid は、同じ行のマス（`<li>`）の高さをそろえる**。一番高いカードに合わせて伸びる
2. **`<li>` を flex にして、中の Card を `flex: 1` で伸ばす**。Card もマスの高さいっぱいになる
3. **Card の `.footer` の `margin-top: auto`** が余った高さを上に取り、ボタンが一番下に寄る

```css
.item {
  display: flex;
}

.item > * {
  flex: 1;
}
```

Grid がマスをそろえ、Flexbox がマスの中身を並べる。

## 部品は自分の幅を決めない

Card にはもともと `max-width: 24rem` を付けていたが、消した。付けたままだと、CardList のマスが 24rem より広いときに、カードがマスいっぱいに広がれず横に隙間ができる。

**部品は自分の幅を決めず、置かれた場所に任せる。** 幅を決めるのは、一覧やページの役目。Card はブロック要素なので、何もしなければ親の幅いっぱいに広がる（[docs/05](05-px%20と%20rem.md) の「幅と余白の初期値」）。

Storybook で Card だけを見るときは、ストーリーの外側の `div` で幅を決めている。

```tsx
// Card.stories.tsx
decorators: [
  (Story) => (
    <div style={{ maxWidth: "24rem" }}>
      <Story />
    </div>
  ),
],
```

## 一覧は `<ul>` と `<li>` で作る

カードの一覧は、HTML でも「一覧」として書く。スクリーンリーダーが「リスト、4 項目」のように読み上げ、いくつあるかが伝わる。

`<ul>` にはブラウザが黒丸と余白を付けるので、CSS で消している。

```css
.list {
  list-style: none;
  margin: 0;
  padding: 0;
}
```
