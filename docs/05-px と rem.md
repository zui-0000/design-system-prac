# px と rem

記録日: 2026-10-17

段階 1 で Card を作ったときに学んだ、長さの単位の使い分け。

## rem とは

`rem` は「**ルートの文字サイズの何倍か**」で表す単位。"root em" の略。

- ルートは、ページの一番外側の `<html>` 要素
- ブラウザの初期設定では、`<html>` の文字サイズは **16px**

初期設定のままなら、次のようになる。

| rem       | px    |
| --------- | ----- |
| `0.5rem`  | 8px   |
| `0.75rem` | 12px  |
| `1rem`    | 16px  |
| `1.5rem`  | 24px  |
| `24rem`   | 384px |

## px ではなく rem を使う理由

**ユーザーが文字を大きくしたときに、一緒に大きくなるため。**

視力の弱い人は、ブラウザの設定で標準の文字サイズを上げることがある（例: 16px → 24px）。

| 書き方            | 標準の文字サイズを 24px にした場合  |
| ----------------- | ----------------------------------- |
| `font-size: 16px` | 16px のまま。設定が無視される       |
| `font-size: 1rem` | 24px になる。設定どおりに大きくなる |

文字だけ大きくなって余白が px のままだと、窮屈になって崩れやすい。余白も rem で書けば、全体の比率を保ったまま大きくなる。

TS で言えば、`16` という値を直接書くか、`BASE * 1.5` と基準からの倍数で書くかの違い。基準（ルートの文字サイズ）が変わっても、倍数で書いた側はすべて追従する。

## em との違い

`em` は「**その要素自身の文字サイズ**の何倍か」。

- 文字サイズは親から受け継がれるので、入れ子にすると掛け算になる（`1.2em` の中の `1.2em` は 1.44 倍）。同じ値でも、置かれた場所で結果が変わる
- `rem` は基準が `<html>` の 1 つだけなので、どこに書いても結果がぶれない

## 使い分け

| 単位  | 使う場面                                                 |
| ----- | -------------------------------------------------------- |
| `rem` | 文字サイズ・余白・幅の上限など、ほとんどの値             |
| `px`  | 枠線の `1px` など、文字と一緒に大きくなると困る細い線    |
| `em`  | その部品の文字の大きさに合わせて変えたい、特別な場合だけ |

Card（`src/components/ui/Card/Card.module.css`）でも、余白・角丸・幅の上限は rem、枠線だけ `1px` にした。

補足: 行の高さ（`line-height`）は単位なしで書く（`global.css` の `line-height: 1.5`）。文字サイズの 1.5 倍になり、文字サイズが変わっても追従する。

## 試し方

ブラウザの設定（Chrome なら「設定 → デザイン → フォントサイズ」）で文字を「特大」にして、Storybook の Card を見る。文字と一緒に余白も広がる。

## ズームとの違い

ブラウザのズーム（`Cmd` + `+`）でも画面は大きくなるが、文字サイズの設定とは仕組みが違う。

|                            | ズーム（`Cmd` + `+`）            | 文字サイズの設定                            |
| -------------------------- | -------------------------------- | ------------------------------------------- |
| 大きくなるもの             | **すべて**。px も rem も画像も   | **rem と em だけ**                          |
| px で書いた値              | 大きくなる                       | そのまま                                    |
| 仕組み                     | 1px を描く画面上の大きさを変える | `<html>` の文字サイズ（rem の基準）を変える |
| 画面の幅（CSS から見た幅） | 狭くなる（200% なら半分）        | 変わらない                                  |

- ズームでは px も rem も同じだけ大きくなるので、**px と rem の違いは見えない**。違いを確かめるなら、文字サイズの設定を使う
- ズームすると CSS から見た画面の幅が狭くなる。幅 1280px の画面を 200% にすると、CSS からは幅 640px に見え、スマホ向けのレイアウト（メディアクエリ）に切り替わることがある

ユーザーはどちらの方法も使うので、両方に備える。

- **ズーム**: px でも大きくなる。狭い画面のレイアウトに切り替わったときに崩れないかを確かめる
- **文字サイズの設定**: px で書いた文字や余白は大きくならない。だから rem で書く

WCAG（Web のアクセシビリティの国際基準）にも、文字を 200% に拡大しても内容や機能が失われないこと、という項目がある（[1.4.4 Resize Text](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)）。

Mac の Chrome のキー: `Cmd` + `+`（または `Cmd` + `=`）で拡大、`Cmd` + `-` で縮小、`Cmd` + `0` で元に戻す。
