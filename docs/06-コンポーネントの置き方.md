# コンポーネントの置き方

記録日: 2026-10-18

`src/components/` の下を、部品（`ui/`）とページ（`pages/`）に分けた。2 つはファイルの名前の付け方が違う。Claude Code 向けには `.claude/rules/components.md` に同じ決まりを書いている。

## 構成

```
src/components/
├── ui/                  部品
│   └── Card/
│       ├── Card.tsx
│       ├── Card.module.css
│       └── Card.stories.tsx
└── pages/               ページ
    └── Practice/
        ├── index.tsx    export function PracticePage()
        └── index.module.css
```

| 置き場所 | ファイル名                                  | 使われ方                                       |
| -------- | ------------------------------------------- | ---------------------------------------------- |
| `ui/`    | 部品の名前（`Card.tsx`・`Card.module.css`） | ページやほかの部品から、何度も組み合わせて使う |
| `pages/` | `index.tsx`・`index.module.css`             | `src/routes/` から 1 回だけ使う。URL と 1 対 1 |

どちらも **1 つのフォルダに 1 つ**（部品なら 1 部品、ページなら 1 ページ）。TS で言えば package by feature で、関係するファイルが 1 か所にまとまり、消すときもフォルダごと消せる。

## 部品（`ui/`）は名前付きのファイルにする

部品は、**パーツの組み合わせ**で作ることが多い。

```tsx
<Card>
  <CardHeader>
    <CardTitle>見出し</CardTitle>
  </CardHeader>
  <CardContent>本文</CardContent>
</Card>
```

パーツごとにファイルを分けると、1 つのフォルダに何枚も入る。

```
ui/Card/
├── Card.tsx
├── CardTitle.tsx
├── CardFooter.tsx
└── Card.module.css
```

本体だけを `index.tsx` にすると、どれが本体か名前から分からなくなる。名前をそろえておけば、ファイルの一覧がそのまま部品の設計図になる。全部が `index.tsx` だと、エディタのタブで見分けにくいという問題もある。

ストーリー（`Card.stories.tsx`）も同じフォルダに置き、部品を作ったら必ず書く。Storybook で一覧にするのがこのリポジトリの目的のため。

### パーツを 1 ファイルにまとめるか分けるか（未決定）

ライブラリによって書き方が違う。

| ライブラリ | パーツの書き方                                                             | ファイル                                         |
| ---------- | -------------------------------------------------------------------------- | ------------------------------------------------ |
| shadcn/ui  | `Card`・`CardHeader`・`CardTitle` などを別々の名前で export                | `components/ui/card.tsx` の 1 ファイルにまとめる |
| Base UI    | `Dialog.Root`・`Dialog.Trigger`・`Dialog.Popup` のように名前空間でまとめる | ライブラリ側にある。使う側はラップする           |

段階 3（Base UI + CSS Modules）で、パーツのある部品を作るときに決める。どちらにしても「`index.tsx` にしない、名前付きのまま」という決まりは変わらない。

## ページ（`pages/`）は `index.tsx` にする

ページは 1 枚で完結し、パーツに分けて外から組み合わせることがない。`Practice/index.tsx` で「Practice フォルダの中身がページ本体」と読めれば十分。

- フォルダ名はページの名前（PascalCase）。関数名は `PracticePage` のように `Page` を付ける
- import はフォルダまで書けば、中の `index.tsx` が読まれる（`"../components/pages/Practice"`）。npm のパッケージで、入口の `index.js` が読まれるのと同じ仕組み
- 経路の宣言はページに書かず、`src/routes/` に書く（[docs/07](07-ルーティング.md)）
