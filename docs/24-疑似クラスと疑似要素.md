# 疑似クラスと疑似要素

記録日: 2026-11-07

CSS のセレクタは、ふつう HTML に書いてあるもの（タグの名前・クラス・属性）で要素を選ぶ。疑似クラスと疑似要素は、**HTML に書いていないもの**を選ぶ書き方。

| 書き方    | 種類       | 選ぶもの                     | 例                                                    |
| --------- | ---------- | ---------------------------- | ----------------------------------------------------- |
| `:` 1 つ  | 疑似クラス | 要素が**どんな状態か**       | `:hover`・`:focus-visible`・`:required`・`:has()`     |
| `::` 2 つ | 疑似要素   | 要素の**どの部分か**（足す） | `::placeholder`・`::before`・`::after`・`::selection` |

```css
.button:hover {}          /* マウスが乗っている .button */
.control::placeholder {}  /* .control の中の、placeholder の文字 */
```

TS で言えば、疑似クラスは要素を絞り込む条件（`elements.filter((el) => el.isHovered)`）、疑似要素は要素のプロパティ（`input.placeholder`）に近い。

## 疑似クラス: 状態で選ぶ

マウスが乗っている、フォーカスしている、入力が必須だ、といった状態は、HTML には書いていない。ブラウザが知っているので、疑似クラスで選べる（docs/14 の「ブラウザが知っている状態」）。

### ユーザーの操作

| 疑似クラス       | いつ付くか                                             | このリポジトリの例             |
| ---------------- | ------------------------------------------------------ | ------------------------------ |
| `:hover`         | マウスが乗っている                                     | Button の色を変える            |
| `:active`        | 押している間                                           | Button の押した色              |
| `:focus-visible` | キーボードでフォーカスした（マウスで押したときは除く） | Button の輪、入力欄の枠の輪    |
| `:focus-within`  | 自分か、中のどれかにフォーカスがある                   | 使っていない（理由は docs/23） |

`:focus` は、マウスで押したときにも付く。押すたびに輪が出るのを避けるため、輪には `:focus-visible` を使う。

### 入力欄の状態

| 疑似クラス           | いつ付くか                         | このリポジトリの例                           |
| -------------------- | ---------------------------------- | -------------------------------------------- |
| `:required`          | `required` が付いている            | ラベルの「必須」（`.field:has(:required)`）  |
| `:invalid`           | ブラウザの検証で失敗している       | 使っていない（下の「`data-*` との違い」）    |
| `:placeholder-shown` | placeholder が見えている（空の欄） | `reset.css`                                  |
| `:disabled`          | `disabled` が付いている            | 使っていない（Base UI の `[data-disabled]`） |
| `:checked`           | チェックボックスなどがオン         | 使っていない（Base UI の `[data-checked]`）  |

### 条件を組み立てる

中にセレクタを書いて、条件を組み立てる疑似クラス。

| 疑似クラス  | 意味                               | このリポジトリの例                              |
| ----------- | ---------------------------------- | ----------------------------------------------- |
| `:not(…)`   | 〜でない                           | `.button:hover:not([data-disabled])`（docs/13） |
| `:has(…)`   | 中に〜がある（親が子の状態を見る） | 入力欄の枠の色、「必須」の印（docs/23）         |
| `:is(…)`    | どれかに当てはまる（まとめ書き）   | `reset.css`                                     |
| `:where(…)` | `:is()` と同じだが、強さが 0       | `reset.css` のほとんど（docs/12）               |

### `data-*` との違い

Base UI は、状態を `data-*` の属性で付ける（`data-invalid`・`data-disabled` など）。これは疑似クラスではなく、ただの属性なので `[data-invalid]` と `[]` で選ぶ。

ブラウザの疑似クラスがあっても、Base UI の属性を使う場面がある。`:invalid` は、打つ前の空の欄でも `required` なら付くので、開いた瞬間から赤い枠になる。Base UI の `data-invalid` は、送信して検証したあとにだけ付く（docs/23）。

## 疑似要素: 部分を選ぶ・足す

### 部分を選ぶ

要素の中に、ブラウザが描いているがタグのない部分がある。疑似要素で、そこだけに色などを付けられる。

| 疑似要素                 | 選ぶもの                             | このリポジトリの例             |
| ------------------------ | ------------------------------------ | ------------------------------ |
| `::placeholder`          | 入力欄の placeholder の文字          | 入力欄で、補足の文字の色にする |
| `::selection`            | マウスで選んだ文字                   | 使っていない                   |
| `::backdrop`             | ダイアログの後ろの、画面を覆う幕     | `reset.css`                    |
| `::file-selector-button` | ファイルを選ぶ欄の「ファイルを選択」 | `reset.css`                    |

`::placeholder` は、ブラウザによって初めの濃さが違う（Firefox は初めから薄い）。`reset.css` で `opacity: unset` にして、そろえている。

### 中身の前後に足す（`::before`・`::after`）

`::before` と `::after` は、HTML を書かずに、要素の中身の最初と最後に箱を 1 つずつ足す。**`content` を書かないと現れない**。文字を出さない飾りでも `content: ""` を書く。

Switch では、見えない `::after` を上下にはみ出させて、押せる範囲を 44px に広げた（docs/15）。

```css
.switch::after {
  content: "";
  position: absolute;
  inset-inline: 0;
  top: 50%;
  height: var(--size-touch-target);
  translate: 0 -50%;
}
```

`::after` は `.switch` の一部なので、そこを押しても `.switch` を押したことになる。HTML に `<span>` を足さずに済み、読み上げソフトにも余計なものが増えない。

足せない要素もある。文字を打つ `<input>` と `<img>` は、中身を持たない要素なので、`::before`・`::after` が出ない。入力欄の中にアイコンを置くのに、外側に枠の `<div>` を作ったのも同じ理由（docs/23）。

## 強さ（詳細度）

同じ要素に 2 つのルールが当たったとき、どちらが勝つかの強さ（docs/12）。

| 書き方                           | 強さ                                   |
| -------------------------------- | -------------------------------------- |
| 疑似クラス（`:hover` など）      | クラスと同じ                           |
| 疑似要素（`::placeholder` など） | タグの名前と同じ                       |
| `:where(…)`                      | 0                                      |
| `:is(…)`・`:not(…)`・`:has(…)`   | 中に書いたセレクタのうち、一番強いもの |

`reset.css` は `:where()` で強さを 0 にしているので、部品のクラスに必ず負ける。ただし `::placeholder` のような疑似要素は `:where()` の外に出るので、タグの名前の強さが残る（docs/12）。

## コロン 1 つで書く疑似要素

`:before`・`:after`・`:first-line`・`:first-letter` の 4 つは、昔のコロン 1 つの書き方でも動く。`::` で書き分けるようになる前の名残。このリポジトリでは、疑似要素は必ず `::` で書く。疑似クラスと見分けが付くため。

## 試し方

- **疑似クラス**: 開発者ツールの Elements（要素）で要素を選び、Styles の `:hov` を押す。`:hover`・`:focus-visible` などにチェックを入れると、マウスを乗せなくても、その状態の見た目になる
- **疑似要素**: Elements で入力欄を開くと `::placeholder` が、Switch を開くと `::after` が、子の要素のように並ぶ。選ぶと、その部分のスタイルが見られる
